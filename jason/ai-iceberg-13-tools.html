水面上：大家都在用的那一個

1. ChatGPT

一句話：最多人用的 AI 助手，寫作、問答、構思、生圖、語音對話全包。

適合誰：所有人。第一個 AI 工具就從這裡開始。

網址與下載

  • 網頁版：https://chatgpt.com
  • 手機 App：App Store / Google Play 搜尋「ChatGPT」（開發商 OpenAI，認明官方）
  • 電腦版：https://chatgpt.com/download（macOS / Windows）

上手步驟

  1. 用 Google 或 Email 註冊帳號
  2. 左下角頭像 → 設定 → 個人化 → 自訂指令，寫下你是誰、你在做什麼帳號、你希望它怎麼回答
  3. 開一個 專案（Projects），例如「我的 IG 帳號」，把帳號定位、過往爆文丟進去當資料
  4. 之後所有跟帳號有關的對話都在這個專案裡開，它會記得脈絡

自媒體實用 Prompt（直接複製）

你是一位熟悉台灣 IG 生態的內容策略師。
我的帳號定位：【填入你的定位，例如：上班族理財入門】
我的目標受眾：【填入，例如：25-35 歲剛開始存錢的上班族】

請幫我產出 10 個輪播貼文選題，每個選題附上：
1. 封面標題（15 字內，要讓人停下滑動）
2. 這篇解決受眾的什麼問題
3. 建議的 CTA 留言關鍵字

進階用法

  • GPTs：把常用的 Prompt 做成專屬機器人，例如「我的標題產生器」
  • 生圖：直接在對話裡要求生成封面圖、示意圖
  • 語音模式：通勤時用講的發想點子

注意事項

  • 免費版有使用上限，重度使用建議升級
  • 事實、數據類內容一定要自己查證

自媒體實用 Prompt（直接複製）

以下是我一支影片的逐字稿。請幫我：
1. 拆成一篇 IG 輪播貼文（7 張，每張標題 + 正文）
2. 寫一篇 150 字內的 IG 說明文案
3. 寫一篇 80 字內的 Threads 文案
語氣：口語、直接、像朋友聊天。不要用「不是……而是……」這種句型。

逐字稿：
【貼上逐字稿】

注意事項

  • 免費版額度較少，長文件處理建議用 Pro
  • 「Artifacts」功能可以直接產出網頁、表格、文件，適合做 Lead Magnet

3. ElevenLabs

一句話：目前最自然的 AI 配音工具，可以複製你自己的聲音。

適合誰：不想露臉、不想錄音、要做多語言影片的創作者。

網址與下載

  • 網頁版：https://elevenlabs.io
  • 手機 App：App Store / Google Play 搜尋「ElevenLabs」（ElevenReader 是朗讀用 App，配音創作以網頁版為主）

核心功能

  • Text to Speech：貼上文字，選聲音，產出配音，支援中文
  • Voice Cloning：錄一段自己的聲音，之後打字就能用你的聲音說話（需付費方案）
  • Dubbing：把影片翻譯成其他語言並配音，保留原本的聲線

上手步驟

  1. 註冊後進入 Text to Speech
  2. 從 Voice Library 挑一個中文聲音，或先用預設聲音試
  3. 貼上腳本，調整 Stability（穩定度） 和 Similarity（相似度）
  4. 產出後下載 MP3，丟進剪映 / CapCut 對嘴或配畫面

實用技巧

  • 腳本裡用「，」「。」「……」控制停頓，比調參數有效
  • 數字和英文縮寫寫成你希望的唸法，例如「AI」寫成「A I」
  • 複製聲音時，錄音環境安靜、講話自然，效果比照稿念好

注意事項

  • 複製別人的聲音需要對方同意，商用前確認你的方案授權

4. Higgsfield

一句話：AI 影片生成平台，強項是電影感的運鏡效果。

適合誰：做短影音、廣告素材、想要畫面有質感但沒有拍攝預算的人。

網址：https://higgsfield.ai

核心功能

  • 圖片轉影片：上傳一張圖，選運鏡方式（推近、環繞、俯衝……），產出動態影片
  • 文字轉影片：描述畫面直接生成
  • 多模型整合：平台內可以切換不同的影片 / 圖片生成模型

上手步驟

  1. 註冊帳號（免費方案可用功能有限，主要靠付費點數）
  2. 先用 圖片轉影片：上傳你的產品照或人物照
  3. 從運鏡預設裡挑一個效果
  4. 產出 5–10 秒片段，下載後拿去剪輯

實用 Prompt 寫法

A slow cinematic push-in on a coffee cup on a wooden desk,
morning sunlight through the window, soft steam rising,
shallow depth of field, warm tones.
💡 英文描述效果通常比中文穩定。結構：主體 ＋ 動作 ＋ 場景 ＋ 光線 ＋ 風格。

注意事項

  • 點數消耗依模型不同差很多，先用便宜的模型測構圖，滿意再用高階模型出成品

5. Lovable

一句話：用打字描述，AI 幫你做出完整網站或 App，不用會寫程式。

適合誰：想做銷售頁、預約系統、會員頁、小工具，但沒有工程師的人。

網址：https://lovable.dev

上手步驟

  1. 註冊帳號，免費方案每天有額度可以試
  2. 首頁對話框直接描述你要的東西（範例見下方）
  3. AI 產出畫面後，用對話繼續修改：「按鈕改成橘色」「加一個常見問題區塊」
  4. 右上角 Publish 發佈，拿到網址
  5. 要存會員資料、表單資料，可以連接 Supabase（Lovable 內建整合）

實用 Prompt（直接複製）

幫我做一個線上課程的銷售頁，課程名稱是「【課程名稱】」。
需要以下區塊：
1. 首屏：大標題、副標、立即報名按鈕
2. 你會學到什麼（4 個重點，附 icon）
3. 講師介紹（照片、簡介）
4. 學員見證（3 則）
5. 價格方案（早鳥價 / 原價）
6. 常見問題（5 題，可展開）
風格：簡潔、米白底、深色字、橘色強調。手機版要好看。

注意事項

  • 一次描述越完整，修改次數越少，越省額度
  • 綁自己的網域需要付費方案

6. Stripe

一句話：全球最常用的線上收款服務，可以收信用卡、做訂閱制、產生付款連結。

適合誰：賣線上課程、數位商品、會員訂閱，客群包含海外的人。

網址：https://stripe.com

最簡單的用法：Payment Links（付款連結）
不用寫程式，做法：

  1. 登入 Stripe 後台 → Product catalog 建立商品與價格
  2. 進入 Payment Links → 建立連結
  3. 把連結放到 IG 簡介、Lovable 做的銷售頁、私訊裡
  4. 客人付款後，後台會收到通知，也可以設定自動寄送收據

可以做的事

  • 一次性付款（課程、電子書）
  • 訂閱制（月費社群、會員）
  • 折扣碼、早鳥價

⚠️ 台灣使用者必讀

  • 台灣註冊的公司目前不在 Stripe 官方開放的國家清單內，請先到 https://stripe.com/global 確認最新狀態
  • 常見做法：用海外公司（例如透過 Stripe Atlas 成立美國公司）開戶
  • 如果客群主要在台灣，本地金流（例如綠界、藍新）通常申請更快，也支援超商代碼、ATM 轉帳

注意事項

  • Stripe 沒有月費，按每筆交易收手續費，費率以官網為準
  • 涉及公司設立、稅務的部分，建議先問會計師

7. Codex

一句話：OpenAI 的 AI 程式碼助手，可以幫你寫程式、改程式、修 bug。

適合誰：想自己做小工具、自動化腳本、改網站的人。

網址

  • 官方介紹：https://chatgpt.com/codex
  • 開發者文件：https://developers.openai.com/codex

三種使用方式

  1. ChatGPT 裡直接用：在 ChatGPT 側邊欄找到 Codex，連結 GitHub 專案後在雲端執行
  2. Codex App：圖形介面版，適合不熟終端機的人
  3. Codex CLI（終端機版）：

macOS / Linux：

curl -fsSL https://chatgpt.com/codex/install.sh | sh

用 Homebrew（Mac）：

brew install --cask codex

用 npm：

npm install -g @openai/codex

上手步驟（CLI）

  1. 安裝完輸入 codex --version，有出現版本號就成功
  2. 進入你的專案資料夾，輸入 codex
  3. 第一次會要求登入，用 ChatGPT 帳號登入即可
  4. 直接用中文交代任務

實用指令範例

幫我寫一個 Python 程式：讀取這個資料夾裡所有的 CSV 檔，
把「日期」「觸及」「互動數」三個欄位合併成一張表，
依照互動數排序，輸出成 report.xlsx

注意事項

  • 使用額度跟你的 ChatGPT 方案綁定
  • 它會修改你的檔案，重要專案先備份或用 Git 管理

送出後顯示「已收到，資料會寄到你信箱」。
風格簡潔，手機版優先。做完告訴我怎麼在本機預覽。

9. Manus

一句話：AI 代理工具，交代一個任務，它自己上網查資料、整理、產出成品。

適合誰：常做市場調查、競品分析、整理資料、做簡報的人。

網址與下載

  • 網頁版：https://manus.im
  • 電腦版、手機 App：官網有下載入口（電腦版可以讓 Manus 操作你本機的檔案與工具）

上手步驟

  1. 註冊帳號（免費方案有額度可試）
  2. 在對話框描述一個 有明確產出 的任務
  3. 它會在右側顯示執行過程：開了哪些網頁、寫了哪些檔案
  4. 完成後下載成品（報告、簡報、表格、網頁）

實用任務範例（直接複製）

幫我研究台灣 IG 上分享「AI 工具教學」的前 15 個帳號。
整理成一張表：帳號名稱、追蹤數、主要內容類型、
發文頻率、最常用的貼文格式、CTA 方式。
最後用 5 點總結：這個領域還有哪些內容缺口。

注意事項

  • 任務越複雜，消耗點數越多，先用小任務測試
  • 輸出的數據要抽查，AI 代理也會抓錯資料

npx n8n

然後打開瀏覽器進入 http://localhost:5678

11. MCP（Model Context Protocol）

一句話：一套開放標準，讓 AI 可以直接連上你的 Notion、Google Drive、Slack 等工具並操作它們。

適合誰：已經習慣用 AI，想讓 AI 直接讀寫你工作資料的人。

網址：https://modelcontextprotocol.io

用白話解釋
以前：你要把 Notion 的內容複製貼上給 AI，AI 回答完你再貼回去。
有 MCP：AI 直接讀你的 Notion、直接幫你建頁面。

MCP 本身是「接頭規格」，你不需要安裝 MCP 這個東西，你要用的是「支援 MCP 的 AI」＋「各工具的 MCP 連接器」。

最簡單的開始方式

  1. Claude：設定 → Connectors（連接器），直接連接 Notion、Google Drive、Gmail 等
  2. ChatGPT：設定裡的應用程式 / 連接器區塊，也支援連接外部工具
  3. Claude Code：終端機輸入 claude mcp add 加入 MCP 伺服器

實用情境

  • 「讀我 Notion 裡的選題資料庫，挑出還沒寫的 5 個，幫我各寫一版大綱，存回 Notion」
  • 「看我 Google Drive 裡上個月的數據報表，告訴我哪三篇表現最好、共同點是什麼」

注意事項

  • 只連接你信任的官方或知名連接器
  • 給 AI 寫入權限前，先確認它要改哪些東西

12. Clay

一句話：名單拓展工具，從一個公司名或人名，自動補齊聯絡方式與背景資料。

適合誰：接業配、找合作品牌、做 B2B 服務、需要開發客戶的人。

網址：https://www.clay.com

核心功能

  • Waterfall Enrichment：依序查詢多個資料來源，盡量補齊 Email、職稱、公司資訊
  • Claygent：AI 研究員，幫你上網查每一筆名單的背景
  • AI 欄位：根據查到的資料，自動寫出個人化開發信開頭

上手步驟

  1. 註冊帳號（免費方案有點數可試）
  2. 建立新 Table，匯入名單（CSV 或從 LinkedIn 等來源）
  3. 新增欄位 → 選擇要補的資料（公司網站、聯絡人、Email）
  4. 新增 AI 欄位，寫指令產出個人化內容

AI 欄位指令範例

根據這家公司的官網內容與最近動態，
寫一句 30 字內的開發信開場白，
點出他們最近在做的事，語氣自然，不要恭維。

注意事項

  • 介面偏英文、功能多，建議先看官方教學影片
  • 寄送開發信要遵守當地法規，對方表示不需要就停止聯繫

13. Apify

一句話：網頁資料擷取平台，有上千個現成的「爬蟲小程式」可以直接用。

適合誰：要抓競品貼文數據、Google 地圖店家名單、電商商品資料的人。

網址：https://apify.com

上手步驟

  1. 註冊帳號，免費方案每月有使用額度
  2. 進入 Apify Store，搜尋你要的資料來源，例如：
    • Instagram Scraper：抓公開帳號的貼文、互動數
    • Google Maps Scraper：抓特定地區、特定類型的店家資訊
    • TikTok Scraper：抓公開影片數據
  3. 填入目標（帳號名稱、關鍵字、網址），設定要抓幾筆
  4. 按 Start，跑完後下載成 Excel / CSV / JSON

自媒體實用情境

  • 抓 5 個對標帳號最近 50 篇貼文 → 丟給 Claude 分析「哪類主題互動最高」
  • 抓「台北 咖啡廳」Google 地圖名單 → 做在地業配開發清單

注意事項

  • 只抓公開資料，遵守各平台使用條款
  • 涉及個人資料（姓名、電話、Email）要遵守個資法規範，不要拿去濫發訊息

3 套自媒體變現組合技

單一工具省時間。串起來，才會變成生意。

組合 1｜一份內容，產出 5 個平台的素材

用到：Claude ＋ ElevenLabs ＋ Higgsfield ＋ ChatGPT

  1. Claude：把一篇長文 / 逐字稿改寫成短影音腳本、輪播文案、Threads 文案
  2. ElevenLabs：短影音腳本轉成配音
  3. Higgsfield：產出配合腳本的 B-roll 畫面
  4. ChatGPT：生成輪播封面圖
  5. 剪映 / CapCut 合成，排程發佈

省下的時間：原本一整天的工作，壓到 2–3 小時。

組合 2｜24 小時做出一個能收錢的數位商品

用到：Claude ＋ Lovable ＋ Stripe（或本地金流）＋ n8n

  1. Claude：整理你的專業知識，寫成電子書或模板包
  2. Lovable：做一頁式銷售頁
  3. Stripe Payment Links（或綠界、藍新）：產生付款連結放上銷售頁
  4. n8n：付款成功 → 自動寄出商品連結 → 把買家存進名單

重點：第一個商品定價低一點，目的是驗證「有人願意付錢」。

組合 3｜主動找業配與合作對象

用到：Apify ＋ Clay ＋ Claude ＋ Manus

  1. Manus：研究你這個領域常下廣告的品牌有哪些
  2. Apify：抓這些品牌近期合作過的創作者、貼文數據
  3. Clay：補齊品牌行銷窗口的聯絡資訊
  4. Claude：根據每個品牌的狀況，寫個人化的合作提案信

重點：提案信附上你的數據與 1 個具體企劃點子，回覆率會高很多。
