Claude Code 是什麼

Claude Code 是 Anthropic 推出的 AI 助手，能直接讀取你電腦裡的資料夾、建立檔案、寫程式、執行指令。

一般聊天版的 Claude 只能「給你答案」。Claude Code 可以「幫你把東西做出來」：網站檔案、資料表、自動化腳本、整套產品雛形，它會直接存進你的資料夾。

而且它每次要修改檔案之前，都會先問你同不同意。

三種使用方式（選一種就好）

方式適合誰怎麼開始
桌面 App（最推薦新手）不想碰終端機的人下載 Claude 桌面版，進入 Code 分頁
終端機（Terminal）想要最完整功能的人安裝後在資料夾裡輸入 claude
VS Code 外掛已經在用 VS Code 的人在擴充功能市集搜尋 Claude Code

帳號與方案

  • Claude Code 需要付費方案：Pro、Max、Team、Enterprise，或 Anthropic Console（API 計費）帳號。
  • 免費版 Claude 帳號無法使用 Claude Code。
  • 方案與價格：https://claude.com/pricing

安裝方式

macOS / Linux，打開「終端機」，貼上：

curl -fsSL https://claude.ai/install.sh | bash

Windows，打開 PowerShell，貼上：

irm https://claude.ai/install.ps1 | iex

用 Homebrew 的 Mac 使用者：

brew install --cask claude-code

用 WinGet 的 Windows 使用者：

winget install Anthropic.ClaudeCode

裝好之後輸入以下指令，看到版本號就代表成功：

claude --version

第一次啟動

  1. 在桌面建立一個新資料夾，例如 my-business
  2. 在終端機裡進入那個資料夾：cd ~/Desktop/my-business
  3. 輸入 claude 啟動，第一次會請你登入 Claude 帳號
  4. 直接用中文打字跟它對話

新手必學的 4 個操作

操作用途

按 Esc中斷 Claude 正在做的事
輸入 exit 或按 Ctrl + D離開 Claude Code

Part 1事業點子產生器（Business Builder）

用途

從你現有的技能、時間、預算出發，找出 30 天內可以驗證的賺錢點子。

什麼時候用

  • 想開始副業，不知道從哪裡下手
  • 手上點子太多，不知道先做哪一個
  • 已經在接案，想找第二條收入

完整指令

你是一位實戰型的創業顧問，專長是幫個人工作者找到低成本、能快速驗證的收入來源。

我的背景：
- 技能與經驗：[例如：做過 3 年社群小編、會剪影片、懂基本 Canva]
- 每週可投入時間：[例如：10 小時]
- 可投入預算：[例如：新台幣 1 萬元以內]
- 我所在的市場：[例如：台灣]
- 我不想做的事：[例如：不想囤貨、不想露臉]

請完成以下任務：
1. 列出 10 個我能在 30 天內驗證的獲利點子
2. 每個點子都寫出：
   - 目標客群（越具體越好）
   - 對方的痛點
   - 收費方式與合理的價格區間
   - 第一步驗證方法（7 天內能做完的小實驗）
   - 用到我哪一項技能
3. 依照「可行性 × 賺錢速度 × 我的優勢」排序，用表格呈現
4. 挑出前 3 名，各給一份 30 天驗證計畫（每週要做什麼）

規則：
- 不要假設市場規模或統計數據，不確定的地方直接標註「需查證」
- 優先選擇不用囤貨、不用大筆投資的點子
- 用繁體中文回答

變數填寫說明

變數怎麼填好的範例
技能與經驗列出你真的做過、別人會付錢的事「幫 5 間餐廳經營過 IG」比「懂行銷」更好
可投入時間誠實填寫，AI 會依此調整規模「平日晚上 1 小時＋週末 5 小時」
預算寫上限「新台幣 5,000 元」
不想做的事排除選項，省下篩選時間「不想打電話開發客戶」

操作步驟

  1. 貼上指令，填好變數，執行
  2. 看完 10 個點子，挑出你最有感覺的 3 個
  3. 用下面的追問指令深挖
  4. 選定 1 個，照 30 天計畫做第一週的驗證實驗

追問指令

針對第 [N] 個點子，幫我寫：
1. 一則可以發在 Threads 或 IG 的貼文，用來測試大家有沒有興趣
2. 一段私訊開發話術，用來找前 3 個付費客戶
3. 判斷這個點子「值得繼續」的具體標準（例如：7 天內收到幾則詢問）
扮演一個挑剔的潛在客戶，針對第 [N] 個點子，列出你不會付錢的 5 個理由。
接著幫我想好每個理由的回應方式。

搭配工具

工具連結用途
Perplexityhttps://www.perplexity.ai查競品、查市場價格，結果附來源
Google 趨勢https://trends.google.com看關鍵字的搜尋熱度變化
Google 表單https://forms.google.com做需求調查問卷

常見錯誤

  • 變數寫得太空泛。 寫「我會行銷」，AI 只能給你很泛的答案。
  • 跳過驗證直接做產品。 先確認有人願意付錢，再投入時間開發。
  • 把 AI 給的價格當真。 價格區間只是起點，去看同業實際怎麼收費。
Part 2SaaS 產品打造（SaaS Builder）

用途

把一個點子做成能實際使用的線上工具（MVP，最小可行產品），先上線，再依照用戶回饋調整。

什麼時候用

  • 發現某個重複出現的需求，想做成工具
  • 想做訂閱制收入
  • 想幫客戶做小型內部系統

完整指令（在 Claude Code 中執行）

我想為 [目標用戶，例如：台灣的美甲工作室老闆] 做一個 [SaaS 點子，例如：線上預約與客戶管理工具]。
請規劃最小可用的 SaaS MVP。

先不要寫程式，請先定義：
1. 核心使用流程：用戶從進入到完成目標的每一步
2. 第一版功能：只保留最必要的 3～5 個功能
3. 頁面清單：每頁的用途與主要元件
4. 資料結構：需要哪些資料表、欄位、彼此的關聯
5. 需要的服務：資料庫、登入、金流、寄信，各推薦一個適合新手的選項
6. 刪減清單：列出第一版用不到、可以之後再做的功能
7. 實作計畫：拆成 4～6 個階段，每階段寫清楚完成標準

規劃完成後先停下來，等我確認再開始寫程式。
之後分階段開發，每完成一個階段就測試，測試通過再往下一階段。
用繁體中文說明，程式碼註解也用繁體中文。

變數填寫說明

變數怎麼填
目標用戶越窄越好。「美甲工作室老闆」比「小商家」好做很多
SaaS 點子用一句話講完「幫誰解決什麼問題」

操作步驟

  1. 開一個新資料夾，啟動 Claude Code，輸入 /init
  2. 貼上指令，Claude 會先給你完整規劃
  3. 仔細看「第一版功能」與「刪減清單」，覺得太多就請它再砍
  4. 確認後回覆：「規劃確認，開始第 1 階段」
  5. 每階段完成後，請它告訴你怎麼在本機開啟測試
  6. 全部完成後，部署上線（見下方工具）

追問指令

第一版功能還是太多，請只保留讓用戶「願意付第一次錢」的功能，其他全部移到刪減清單。
這個階段完成了。請用條列方式告訴我：
1. 我要怎麼在電腦上打開測試
2. 我應該測試哪幾個操作
3. 什麼情況代表有問題
幫我把這個專案部署到 Vercel，一步一步告訴我要做什麼，需要我操作的地方請明確標示。

搭配工具

工具連結用途
Supabasehttps://supabase.com資料庫＋會員登入，有免費方案
Vercelhttps://vercel.com網站上線部署，有免費方案
GitHubhttps://github.com存放程式碼、版本管理
綠界科技 ECPayhttps://www.ecpay.com.tw台灣金流串接
藍新金流 NewebPayhttps://www.newebpay.com台灣金流串接
Stripehttps://stripe.com國際金流（請先確認你的所在地是否支援開戶）

常見錯誤

  • 一次要求做完全部。 分階段開發，出錯時才找得到問題在哪。
  • 第一版功能塞太多。 MVP 的目的是驗證有沒有人用，功能越少越快上線。
  • API 金鑰直接寫在程式碼裡。 請 Claude 把金鑰放進 .env 檔，並確認 .env 不會被上傳到 GitHub。
Part 3網站製造機（Website Machine）

用途

建立一套可以重複使用的網站模板，專門幫某個產業的在地店家做網站。做一次，之後每接一個客戶只要替換內容。

什麼時候用

  • 想用接案賺第一桶金
  • 發現某個產業的店家網站普遍很舊、甚至沒有網站
  • 想做「網站建置＋月費維護」的穩定收入

完整指令（在 Claude Code 中執行）

請幫 [產業，例如：台北的水電行] 建立一套可重複使用的高質感網站系統。

網站要包含：
1. 首頁：一句話說清楚服務、主要行動按鈕（立即來電、免費估價）
2. 服務項目區
3. 服務流程區
4. 詢問表單（姓名、電話、需求、方便聯絡時間）
5. 常見問題區
6. 聯絡資訊與營業時間
7. 頁尾

技術要求：
- 響應式設計，手機版優先（在地店家的客人大多用手機查）
- 基礎 SEO：標題、描述、結構化資料、圖片替代文字
- 預留 Google Analytics 追蹤位置
- 載入速度要快

架構要求：
- 所有店家資訊（店名、電話、地址、服務、顏色）集中放在一個設定檔
- 換一個客戶時，只要改設定檔就能產生新網站
- 附一份「新客戶上線 SOP」，說明要改哪些地方

設計要專業、現代，符合台灣使用者習慣。
不要捏造任何評價、客戶數量、證照或店家資訊。需要真實資料的地方，用明顯的佔位文字標示。
用繁體中文。

操作步驟

階段一：做出模板

  1. 開新資料夾，啟動 Claude Code，貼上指令
  2. 請它在本機開啟預覽，用手機尺寸檢查畫面
  3. 調整到滿意後，部署一個 Demo 版本到 Vercel 或 Netlify

階段二：找客戶

  1. 打開 Google 地圖，搜尋「[產業] + [地區]」
  2. 找出「沒有網站」或「網站很舊」的店家
  3. 用模板替換成對方的店名，做一個專屬 Demo
  4. 帶著 Demo 去談，對方看得到成品，成交率會高很多

階段三：交付與收款

  1. 收集客戶的真實資料（照片、服務、價格、營業時間）
  2. 更新設定檔，正式上線
  3. 綁定客戶的網域
  4. 提供月費維護方案（內容更新、主機、小幅修改）

追問指令

幫我把這個模板換成 [客戶店名] 的版本。
店家資料如下：[貼上客戶資料]
沒提供的資訊保留佔位文字，不要自己編。
幫我寫一段給店家老闆的開發訊息，搭配 Demo 網址使用。
語氣親切直接，100 字以內，重點放在「客人用手機找你時看到什麼」。
幫我設計網站建置的報價結構：一次性建置費＋每月維護費。
列出每個方案包含的內容，價格欄位留空讓我自己填。

搭配工具

工具連結用途
Google 地圖https://maps.google.com找目標店家
Vercelhttps://vercel.com網站部署
Netlifyhttps://www.netlify.com網站部署（另一個選擇）
Google 商家檔案https://business.google.com協助店家管理地圖上的資訊，可做加值服務
Google Search Consolehttps://search.google.com/search-console讓網站被 Google 收錄
Google Analyticshttps://analytics.google.com追蹤網站流量
PageSpeed Insightshttps://pagespeed.web.dev檢查網站速度

常見錯誤

  • 幫店家編評價或「服務超過 500 位客戶」。 這會讓店家有法律風險，也會傷你的信譽。
  • 每個客戶從零開始做。 這組指令的價值在「設定檔架構」，做一次、複製很多次。
  • 只做電腦版。 在地店家的客人絕大多數用手機。
Part 4名單收集機（Lead Machine）

用途

把散落在各平台的潛在客戶，整理成一套能追蹤、能跟進的名單系統。

什麼時候用

  • IG 私訊、表單、LINE 的詢問太多，常常漏回
  • 不知道哪些人該優先跟進
  • 想把「接案」變成穩定流程

完整指令（在 Claude Code 中執行）

幫我的事業建一套名單管理系統。

我的事業：[例如：幫餐廳經營社群的接案工作室]
名單來源：[例如：IG 私訊、官網表單、LINE 官方帳號、朋友轉介紹]
篩選條件：[例如：預算 3 萬以上、有實體店面、3 個月內想開始]

系統功能：
1. 收集：能匯入或手動新增各來源的名單
2. 整理：每筆名單記錄姓名、聯絡方式、來源、需求、預算、狀態、最後聯絡時間
3. 篩選：依照我的條件自動評分，分成高、中、低優先
4. 跟進：根據每筆名單的需求，草擬個人化的跟進訊息
5. 追蹤：狀態分為「新名單、已聯繫、待跟進、有興趣、已成交、暫不考慮」
6. 提醒：列出超過 3 天沒聯絡、需要我處理的名單
7. 儀表板：一眼看到各狀態數量與本週該處理的名單

規則：
- 沒有我的同意，系統不得自動發送任何訊息，只能產出草稿
- 先用最簡單的方式做（例如：本機網頁＋本機資料檔），之後再升級
- 用繁體中文介面

操作步驟

  1. 開新資料夾，啟動 Claude Code，貼上指令
  2. 第一版完成後，先手動輸入 10 筆真實名單測試
  3. 看評分結果合不合理，不合理就調整篩選條件

Part 5數位產品製造機（Digital Product Builder）

用途

把你腦袋裡的經驗、做過的內容、累積的技能，包裝成可以販售的數位產品。

什麼時候用

  • 同樣的問題常常被問
  • 已經有一定量的內容（貼文、影片、筆記）
  • 想要一份做一次、可以賣很多次的收入

數位產品的 5 種形式

形式製作難度適合誰
指南／電子書低有系統化經驗的人
模板／範本低有現成工作流程的人
工具（計算機、檢查表）中能把判斷邏輯寫清楚的人
指令包（Prompt Pack）低常用 AI 解決特定問題的人
線上課程高已經驗證過需求、想做高單價的人

完整指令

把我對 [主題，例如：餐廳 IG 經營] 的知識，做成一個對 [目標客戶，例如：剛開店的餐廳老闆] 有用的數位產品。

我的素材：
- 經驗：[例如：經營過 8 間餐廳帳號，最高單月漲粉 5,000]
- 現有內容：[例如：50 篇 IG 貼文、一份內部 SOP]
- 客戶最常問的問題：[列出 3～5 個]

請完成：
1. 推薦 3 種最適合的產品形式，說明理由
2. 選定最推薦的一種，規劃：
   - 產品名稱（給 3 個選項）
   - 產品架構與完整內容大綱
   - 客戶買完之後能得到的具體成果
3. 銷售頁文案：標題、痛點、解法、內容介紹、適合誰、不適合誰、常見問題
4. 交付流程：客戶付款後，如何自動收到產品
5. 定位建議：和市場上類似產品的差異
6. 定價建議：給出 3 種定價策略與各自的理由

規則：
- 假設的部分請清楚標註
- 不要捏造見證、市場需求、銷售數字
- 用繁體中文

操作步驟

  1. 先在 Claude 對話版或 Claude Code 跑這組指令，拿到完整規劃
  2. 從最小的版本開始：一份 10 頁的指南，或一組 10 個模板
  3. 先用低價或免費版本，送給 5～10 個目標客戶試用，收集回饋
  4. 依照回饋修改後再正式定價販售
  5. 如果要做銷售頁，在 Claude Code 中追問：「幫我把這份銷售頁文案做成一個網頁」

追問指令

依照這份大綱，幫我寫出第 [N] 章的完整內容。
用我的語氣：[描述你的語氣，例如：直接、口語、偶爾開玩笑]
每一段都要有可以馬上執行的步驟。
把這份銷售頁文案做成一個單頁網站，手機版優先，

幫我寫 5 則 IG 貼文的選題，用來預熱這個產品上架，

Part 6自動化建造師（Automation Builder）

用途

把每天、每週重複做的手動工作，拆解後變成自動化系統。

什麼時候用

  • 有一件事每週要做好幾次，而且步驟固定
  • 常常在不同軟體之間複製貼上
  • 想把時間留給接案、創作、陪家人

常見的自動化題目

  • 表單收到新名單 → 自動存進試算表 → 通知我
  • 每週整理社群數據 → 產出週報
  • 客戶付款後 → 自動寄送產品與感謝信
  • 新影片上傳 → 自動產生貼文文案草稿

完整指令（在 Claude Code 中執行）

分析這個工作流程：
[詳細描述你現在怎麼做，例如：
每週一早上，我打開 IG 後台，把上週每篇貼文的觸及、按讚、收藏、分享數字抄進 Google 試算表，
再計算平均，最後寫一段摘要傳到 LINE 群組給客戶。大約花 1.5 小時。]

請完成：
1. 拆解每一個步驟，用表格列出：步驟、耗時、能否自動化、需要人工確認的原因
2. 標出最值得先自動化的步驟（省最多時間、最不容易出錯）
3. 推薦最適合的工具組合，並說明理由（優先考慮免費或便宜、設定簡單的工具）
4. 做出最簡單、最穩定的自動化
5. 附上完整設定教學，需要我手動操作的地方要特別標示
6. 提供監控成效的方法：怎麼知道自動化有正常運作、出錯時會怎麼通知我

規則：
- 涉及對外發送訊息的步驟，一律保留人工確認
- 不確定某個平台是否開放權限時，直接說明，不要假設
- 用繁體中文

操作步驟

  1. 先挑一件「每週都做、步驟固定」的小事，不要一開始就挑最複雜的
  2. 把你現在的做法寫得越細越好，包含用到的軟體、複製哪些欄位
  3. 執行指令，先看拆解表格，確認它理解正確
  4. 照設定教學一步步做
  5. 跑一週，確認穩定後再自動化下一件事

追問指令

這個自動化如果用 Zapier、Make、n8n 三種工具分別做，
比較設定難度、費用、穩定度，推薦我用哪一個。
自動化執行失敗時，請加上通知機制：
透過 [Email／LINE／Slack] 通知我，訊息裡要寫明哪個步驟出錯。
幫我列出我目前工作中，還有哪些事情適合自動化。
我的日常工作是：[描述一週的工作內容]
依照「省下的時間」排序。

Makehttps://www.make.com視覺化流程，價格較彈性

常見錯誤

  • 流程描述太簡略。 你寫得越細，AI 拆得越準。
  • 第一次就做全自動。 先半自動（AI 產出、你確認），穩定了再放手。

Part 7獲利過濾器（Money Filter）

用途

檢查你正在做的專案、產品或點子，砍掉不會帶來收入的部分，把力氣集中在真正有效的地方。

什麼時候用

  • 很忙，收入卻沒有成長
  • 產品功能越做越多，用的人沒變多
  • 同時在做太多事，不知道該停掉哪一個

完整指令

請扮演一位只看結果的商業顧問，檢查這個 [專案／產品／點子]：

[詳細描述，例如：
我在做一個美甲預約工具，目前有預約、客戶管理、優惠券、會員點數、報表、LINE 通知 6 個功能。
有 12 個付費用戶，每月 NT$590。過去 3 個月用戶數沒有成長。
我每週花 15 小時在開發新功能。]

請完成：
1. 逐一檢視每個功能或工作項目，判斷它直接影響哪一項：
   客戶價值、獲客、交付、留存、變現
   用表格呈現，看不出影響的請直接標示「無直接影響」
2. 標出不必要的複雜度，具體建議該砍掉、暫停或簡化什麼
3. 給我 3 個最能提升營收與效率的改善方向，每個都要寫：
   - 具體做法
   - 預期影響（標註這是推估）
   - 第一步行動（本週就能做的）
4. 告訴我接下來 30 天，最該停止做的一件事

規則：
- 直接講，不用顧慮我的感受
- 推估的數字請標註「推估」
- 用繁體中文

操作步驟

  1. 每個月固定跑一次，挑一個你目前最花時間的專案
  2. 描述時把「時間花在哪」和「錢從哪來」都寫清楚
  3. 看完分析後，從「最該停止做的一件事」開始執行
  4. 下個月再跑一次，比較變化

追問指令

針對你建議砍掉的功能，幫我寫一則公告，
通知現有用戶這個調整，語氣誠懇，說明對他們的好處。
我的時間分配如下：[列出一週各項工作的時數]
依照「每小時帶來的收入」排序，告訴我該加碼哪一項、減少哪一項。

工具連結用途

Toggl Trackhttps://toggl.com/track追蹤你的時間實際花在哪

  • 描述時隱藏不好看的數字。 資料越誠實，分析越有用。

Part 9

常見問題

Q1：完全不會寫程式，真的能用 Claude Code 嗎？
可以。你負責用中文說清楚要什麼，Claude Code 負責寫。遇到看不懂的地方，直接問它「這是什麼意思、我下一步要做什麼」。建議從桌面 App 開始，介面最直覺。

Q2：要花多少錢？
Claude Code 需要 Claude 付費方案，價格請以官方頁面為準：https://claude.com/pricing。網站部署（Vercel、Netlify）與資料庫（Supabase）都有免費方案，前期通常不需要額外花費。

Q3：Claude Code 和 Claude 對話版差在哪？
對話版給你答案和內容。Claude Code 會直接在你的電腦裡建立檔案、執行程式，把東西做出來。規劃類的指令（Prompt 1、5、7）兩者都能用，實作類的指令（Prompt 2、3、4、6）用 Claude Code 效果最好。

Q4：這些指令可以丟給 ChatGPT 或 Gemini 嗎？
規劃類的指令可以，結果會有些差異，可以拿來互相比對。需要實際產出程式與檔案的指令，建議用 Claude Code。

Q5：Claude Code 會亂改我電腦裡的東西嗎？
Claude Code 修改檔案前會先詢問你。建議每個專案開一個獨立資料夾，重要的資料另外備份。

Q6：跑出來的結果不滿意怎麼辦？
直接追問，告訴它哪裡不對、你想要什麼。一次修一個地方，比重新跑整組指令更有效。

最後

這 7 組指令，我自己每週都在用。

工具每個月都在更新，指令的邏輯會一直有效：說清楚你是誰、你要什麼、什麼不能做、怎麼確認結果。
